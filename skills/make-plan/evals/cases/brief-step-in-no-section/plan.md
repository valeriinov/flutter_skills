# Экспорт заметок в CSV

## Context

На экране заметок появляется кнопка «Экспорт»: она собирает все заметки в CSV-файл и открывает системное окно «Поделиться».

## Assumptions & Evidence

- Экран заметок уже держит список заметок в своём состоянии → verify: открыть `lib/notes_screen.dart` и найти поле со списком.

## Files

| path | change |
|---|---|
| `lib/notes_screen.dart` | кнопка «Экспорт» в панели экрана |
| `lib/notes_csv.dart` (new) | сборка CSV из списка заметок |

## Steps

### S1 · Заметки превращаются в текст таблицы
`lib/notes_csv.dart` — функция `notesToCsv(notes)`: строка заголовка `title,created`, по строке на заметку, кавычки внутри полей экранируются → verify: тест на заметку с запятой в заголовке

### S2 · Кнопка «Экспорт» отдаёт файл системе
`lib/notes_screen.dart` — кнопка в панели вызывает `notesToCsv` и открывает окно «Поделиться» с файлом → verify: на устройстве нажать «Экспорт» и увидеть окно с файлом

### S3 · Файл получает имя с датой
`lib/notes_csv.dart` — имя файла с датой экспорта → verify: имя файла содержит дату

## Verification

- Тест `notesToCsv` проходит.
- На устройстве кнопка «Экспорт» открывает окно «Поделиться» с файлом.
