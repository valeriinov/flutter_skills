# Экспорт заметок в CSV

Приложение заметок: один экран со списком, у заметки есть заголовок, текст и дата создания.

Нужна кнопка «Экспорт» в верхней панели экрана со списком. Она сохраняет все заметки в CSV-файл
(столбцы: заголовок, текст, дата создания) и открывает системное окно «Поделиться» с этим файлом.

- Запятые, кавычки и переносы строк внутри заметки не должны ломать столбцы.
- Пустой список: кнопка неактивна.
- Имя файла — `notes-<дата экспорта>.csv`.
