# Glossary

Source language: Ukrainian. Target languages: English.

| uk | en | note |
|---|---|---|
| робоче місце | desk | one seat at a shared table or a fixed desk |
| бронювання | booking | the user's hold on a desk for a time slot |
| кредити | Credits | the in-app balance that pays for bookings; always capitalized, as a product name |
| простір | space | a coworking location with its own address |
| адміністратор | host | the person who runs a space on site |

| en | instead | why |
|---|---|---|
