# Voice guide (Ukrainian)

Written by the product's UX writer.

- Address the user as «ви», lower-case.
- Our texts help people: адміністраторам — run their space; гостям — book a desk.
- A full stop only when a string has two or more sentences.
- Say «Вибрати», never «Обрати».
- A button names the action it performs, a verb.
